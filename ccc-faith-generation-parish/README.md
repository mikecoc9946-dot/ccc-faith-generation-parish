# CCC Faith Generation Parish website starter

A responsive static website starter for CCC Faith Generation Parish.

## Files
- `index.html` – page content
- `styles.css` – layout and styling
- `script.js` – mobile navigation and footer year

## Render settings
- Service type: Static Site
- Branch: `main`
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: `.`

Before public launch, replace placeholder service times, contact details, and gallery tiles with information and photographs approved by the parish. This is an original starter design, not a copy of the Victoria Island parish's source code.
